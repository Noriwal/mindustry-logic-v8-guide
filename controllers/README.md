# Controladores

Cada controlador recebe uma pasta com um `README.md` de instalação e teste e, quando houver uma versão integral recuperada ou nova, um arquivo `.mlog` pronto para colar. Não arquivar trechos incompletos como versões executáveis.

| Controlador | Função | Estado no repositório |
| --- | --- | --- |
| [Horizon](horizon/README.md) | Onda de bombardeiros em formação, alvos terrestres | Especificação e roteiro de testes; programa integral pendente |
| Flare | Patrulha e caça cooperativa com desvio de torres | Programa integral pendente |
| Nova | Combate, pouso e reparo | Programa integral pendente |
| Quasar | Mineração, seleção de recurso e descarga | Programa integral pendente |
| Fábricas e desmontadores | Controle por capacidade do núcleo e links | Programas integrais pendentes |

Para novos programas, veja [validação](../docs/validation.md) e a [referência do Mindustry Tool](../docs/mindustry-tool.md). O status registra apenas o que está efetivamente versionado aqui, sem desconsiderar testes feitos em conversas anteriores.
